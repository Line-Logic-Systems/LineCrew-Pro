Owner and Admin account security
LineCrew Pro requires two-step verification for Owner and Admin accounts. You will need an authenticator app such as Microsoft Authenticator, Google Authenticator, Authy, 1Password or another TOTP authenticator. If you do not already have one, install one before the secure setup step. LineCrew Pro will show a QR code to scan and then ask for the current 6-digit code.
